# 单 KP + 实时 D 调参

更新提示：后续已固化X轴P=0.58、D=0.010，并将Y轴分段PD设为默认启用。
最新默认参数和固件见[Y轴PD在线启用记录](Y轴PD在线启用记录_20261117.md)中的“后续源码固化”；下文保留早期PD试调配置。

固件：`build/Template_Realtime_PD.hex`。烧录后才支持本次新增的控制路径。

默认仍是原来的单 P：KPX=0.55、KPY=0.18、KDX=0、KDY=0，平均帧数为2。
KDX现在直接作用于单KP控制；不需要开启之前的双KP功能。KDY用于Y轴。

## 发送命令

在SerialPlot的Commands中选择ASCII，命令末尾保留英文分号。

```text
SET SHAPEX 0;
SET KPX 0.55;
SET KDX 0.005;
SET KPY 0.18;
SET KDY 0;
```

KDX/KDY允许范围均为0～0.10，单位为RPM·秒/像素。这个范围是输入限制，不代表大值一定适用。
先固定P，用很小的D观察过冲和静止抖动；有效且稳定后，再小幅提高P比较。
例如X轴可先比较D=0、0.005、0.010，之后才考虑把P从0.55改为0.57。
这些是试调候选，不是已经在实机验证过的最佳值。D过大可能降低跟随速度或放大抖动。

回到原来的单P：

```text
SET SHAPEX 0;SET KDX 0;SET KDY 0;
```

`RESET;`恢复全部编译默认参数。串口修改只存在内存中，复位或断电后恢复默认值。

## 实现与波形

控制速度为原有P输出加上经过一阶低通滤波的误差变化率乘D。低通时间常数为0.06秒。
保留原来的远处增益、限速、速度变化限制、中心停止区和换向先降至零逻辑。
D不能在误差尚未跨过中心时单独要求反向。D=0直接使用原来的P控制函数。
两轴独立；失去目标、退出模式、改变中心/D/平均帧数时清除对应微分历史。
新数据间隔超过0.1秒时，单KP的PD路径也会清除微分历史。

原14通道CSV格式保留：第9/10通道仍是KPX/KPY，第13通道命令计数，第14通道为最后一条命令结果（1成功、-1失败）。
KDX/KDY没有加入波形通道；批量发送时最后一条命令的成功不代表前面每条都成功。

该功能只用于视觉位置外环，没有新增电机速度环，也没有加入积分或目标运动前馈。
旧源码已分别备份为同名文件加`.before_realtime_pd.bak`。
