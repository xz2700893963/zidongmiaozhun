# Y轴分段PD在线启用

## 后续源码固化

根据用户后续“修改一下代码”的要求，已将默认值写入`aim_control.h`并接入`serial_tune.c`的启动/RESET初始化：

- X：单KP PD模式，P=0.58、D=0.010，保留旧的大误差P增强。
- Y：分段PD默认启用，近P=0.18、远P=0.24、近D=0.003、远D=0.0005，近/远边界7/24像素。
- 滤波窗口仍为2帧，原参考中心、限速、斜率、驱动加速度与启停滞环保留。

新固件为`build/Template_X058_Y_PD_Defaults.hex`。需要烧录后，开发板复位才会恢复这组新默认值；
在线串口修改仍只存RAM，不会自动写入Flash。源码已改不代表已烧录。
编译0错误、0警告；回归测试验证了启动默认值、在线改参后RESET恢复、Y轴实际控制路径及超时状态清除。
Y轴动态跟踪表现仍待实机验证。

## X轴保持用户当前设置

启用Y之前读到KPX=0.58、命令序号145。用户已修改过命令框并下发过其他命令，
不能继续把先前的X近P=0.60/远P=0.75当作当前配置。
本轮只下发Y轴命令，没有修改X轴；启用Y后KPX仍为0.58。
仅凭14通道CSV不能完整读回X分段开关、近处P及D等参数，不推断它们的实时值。

## SerialPlot命令框

保留前3个X轴命令框，后3个改为Y轴：

```text
SET KPNY 0.18;SET KPFY 0.24;
SET KDNY 0.003;SET KDFY 0.0005;
SET NEARY 7;SET FARY 24;SET SHAPEY 1;
```

修改数值后用ASCII发送。多命令一组只回显最后一条的结果，必要时逐条发送确认。

仅恢复Y轴原单P（不改X轴）：

```text
SET SHAPEY 0;SET KPY 0.18;SET KDY 0;
```
