# 单KP、1帧：用户确认后的保存结果

用户本轮先反馈“快了”，随后确认“**两轴都能停稳**”。据此保存以下配置，适用范围是本轮实机、目标距离与移动方式；没有证明任意速度/距离下都没有滞后或过冲。

| 项目 | 保存值 |
| --- | --- |
| 平均帧数AVG | 1，直接使用当前完整帧，同时作用X/Y |
| X比例系数KPX | 0.55 |
| XSLEW | 260 RPM/s |
| X驱动器ACC | 240 |
| X最大转速指令 | 15 RPM，沿用原上限 |
| SHAPEX | 0，单KP；分段和阻尼关闭 |
| X/Y参考值 | 5 / 12，保持原校准 |

Y轴控制增益与加速度没有改动；摄像头平均帧数是两轴共用的，所以单独向用户确认了两轴静止后的表现。

## 保存和固件

`aim_control.h`已保存KPX=0.55、SLEWX=260、ACCX=240，`UART_maxcam.h`已保存`UART5_DEFAULT_AVERAGE_FRAMES=1U`。原值备份为对应文件的`.before_validated_avg1.bak`，保留原文件编码。

当前运行参数已在线设置成功。新固件为`build/Template_Single_AVG1_Tuned.hex`，本轮尚未烧录这个保存默认值的版本。烧录后重启或`RESET;`会默认使用本配置；不烧录而复位正在运行的旧版本，会恢复它自己的0.42/260/240、AVG=3默认值。

完整在线命令：

```text
SET SHAPEX 0;SET KPX 0.55;SET SLEWX 260;SET ACCX 240;SET MAXX 15;SET AVG 1;
```

恢复3帧平均可发送`SET AVG 3;`，恢复2帧可发送`SET AVG 2;`。少帧数降低这部分平滑延迟，也可能放大噪声，切换后仍应观察实际表现。
