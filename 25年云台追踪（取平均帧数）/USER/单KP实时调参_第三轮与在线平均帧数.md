## 新增在线平均帧数

为进一步比较反馈平滑与延迟，已在新固件中接入：

```text
SET AVG 1;
SET AVG 2;
SET AVG 3;
```

仅接受1、2、3整数，同时作用于摄像头X、Y坐标。默认仍为3帧，`RESET;`与重启恢复3帧。1帧直接使用当前完整帧，2/3帧为等权滑动平均。改变窗口后清除旧平均历史，从下一完整帧建立新窗口，避免混入旧窗口的数据；串口已收到的半帧不会因此丢弃，也不会伪造新帧或刷新失联计时。

3帧滑动平均对匀速变化信号相对当前帧约滞后一个摄像头帧周期，2帧约半个周期，1帧没有这部分平均延迟。摄像头实际帧周期不能直接用SerialPlot的20 Hz输出周期替代。减少平均帧数可能增加抖动，不保证最终实机跟踪改善，Y轴也需要复核。

新固件：`build/Template_Single_OnlineAverage.hex`。已编译0错误、0警告，尚未烧录，当前运行版本不支持AVG命令。烧录后可从`SET AVG 2;`开始对照，旧固件发送该命令会被拒绝。

新固件开机仍使用单KP=0.42、SLEWX=260、ACCX=240、AVG=3；波形仍为14通道。平均帧数没有独立回传通道，需查看命令计数和结果确认命令被接受；代码已提供获取当前窗口的内部接口。

ARM仿真回归验证：1/2/3帧平均数值、切换时清除旧历史、非法数值拒绝、保留已收到的半帧、切换窗口不伪造新帧、失联清零及RESET恢复3帧；原串口、限速与停机测试也通过。

改动前备份为`UART_maxcam.c.before_online_average.bak`、`UART_maxcam.h.before_online_average.bak`、`serial_tune.c.before_online_average.bak`。没有改成双KP控制，没有修改参考中心和速度上限。
