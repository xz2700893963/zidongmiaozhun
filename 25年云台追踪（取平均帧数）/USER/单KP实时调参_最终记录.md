# 单KP实时调参：已保存的默认参数

**第一轮历史记录：后续第二轮已改为KPX=0.42、SLEWX=260、ACCX=240。当前固件是`build/Template_Single_Refined2.hex`，详见`单KP实时调参_第二轮记录.md`。本页保留第一轮数据用于回退对照。**

用户实机确认：选定组合能跟上移动目标，停住后也稳定。该反馈针对当前测试距离、目标移动方式与设备状态，不代表任意速度和距离都成立。

已写回`aim_control.h`：

```c
#define AIM_KP_X          0.40f
#define AIM_SLEW_X        240.0f
#define AIM_MOTOR_ACC_X   240U
```

单KP控制，`SHAPEX=0`；原有远距离增益增强0.35、加速增强0.55、7/24像素增强阈值保留。Y轴参数和X/Y参考坐标保持原值，X最大转速指令仍为15 RPM。分段KP与阻尼没有启用。

在线复现这一组的完整命令：

```text
SET SHAPEX 0;SET KPX 0.40;SET SLEWX 240;SET ACCX 240;SET MAXX 15;
```

当前运行中的参数已经生效。源代码也已保存，但本轮没有再次烧录：需要烧录`build/Template_Single_Tuned.hex`或Keil新生成的`../OBJ/Template.axf`，重启后才会以本轮参数为默认值。不要再次烧录旧的`Template_Shaped_Control.hex`来保留本轮默认值，它是较早的候选版本。

改写前的头文件备份：`aim_control.h.before_live_tuned_defaults.bak`。修改保持原有文件编码。

## 软件命令框

六行都已切回单KP命令：P1是当前保存组合，其他行是对照组合。自动试调不受六行数量限制，本次曾连续发送更多组合；六行仅作为后续手动选择入口。参数数值在输入框里不代表已发送，仍须点Send，并查看回传KPX、命令计数和结果。

## 验证

修改默认值后，Keil编译0错误、0警告；串口参数解析、限速、超时/退出停机、14通道波形等ARM仿真回归通过。仿真不替代上述实机反馈。

驱动器加减速参数的依据：张大头智控《Emm_V5.0步进闭环驱动说明书Rev1.3》，速度模式章节，曲线增速1 RPM的时间为`(256-acc)*50 us`。这解释了为什么仅调软件SLEW不足以反映全部响应延迟；不等同于已经测得真实机构的加减速时间。
