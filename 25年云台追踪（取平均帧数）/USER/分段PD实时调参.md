# 双轴分段PD位置环试调

最新固件为`build/Template_X058_Y_PD_Defaults.hex`；默认值见[Y轴PD在线启用记录](Y轴PD在线启用记录_20261117.md)中的“后续源码固化”。下文为早期分段试调方案。

固件：`build/Template_Scheduled_PD.hex`。

本次按每个轴各自的绝对像素误差调节P、D，不是按XY合成半径分区：

- `|误差| <= NEAR`：使用近处P、近处D。
- `|误差| >= FAR`：使用远处P、远处D。
- 中间范围：用平滑曲线同时插值P、D，避免参数硬切换。
- 中心停止区仍为±2像素，停稳后达到4像素才重新启动。

新模式不叠加旧的远处35%比例增益，设置的远处P就是该模式实际远处P。
原有限速、转速变化率限制、远处加速阶段的斜率增强、换向先降至零等逻辑保留。
这次没有加入积分或前馈。固件默认仍关闭分段模式，保留原来P=0.55/0.18、D=0、2帧平均，发送命令才启用试调。

## 实时命令

使用USB转TTL串口、ASCII发送，英文分号结束，每批尽量不超过100字符。

| 含义 | X轴 | Y轴 |
|---|---|---|
| 分段开关，0关闭/1启用 | SHAPEX | SHAPEY |
| 近处P | KPNX | KPNY |
| 远处P | KPFX（或KPX） | KPFY（或KPY） |
| 近处D | KDNX（或KDX） | KDNY（或KDY） |
| 远处D | KDFX | KDFY |
| 近处边界，像素 | NEARX | NEARY |
| 远处边界，像素 | FARX | FARY |

P范围0～2，D范围0～0.10；NEAR范围4～1000，FAR范围4～2000，且必须NEAR < FAR。
阈值修改逐条校验；如果要把NEAR设得比当前FAR大，先提高FAR，再提高NEAR。
没有强制限制P近远大小和D近远大小，方便对比；要实现本次目标，应满足P远>P近、D近>D远。

关闭分段后，KPX/KPY成为固定P，KDX/KDY成为固定D，其他近远参数不参与单KP路径。
仅关闭分段不会自动恢复此前的P、D数值。`RESET;`才恢复全部编译默认值。

## 首轮候选（需要实机验证）

| 轴 | 近处P | 远处P | 近处D | 远处D | 近/远边界 |
|---|---:|---:|---:|---:|---:|
| X | 0.50 | 0.75 | 0.005 | 0.001 | 7 / 24像素 |
| Y | 0.16 | 0.25 | 0.003 | 0.0005 | 7 / 24像素 |

建议先只试X轴，Y轴保留原来的设置。在SerialPlot按顺序分别发送以下各行：

```text
SET SHAPEX 0;SET KPNX 0.50;SET KPFX 0.75;
SET KDNX 0.005;SET KDFX 0.001;
SET NEARX 7;SET FARX 24;
SET SHAPEX 1;
```

如果也要试Y轴，再依次发送：

```text
SET SHAPEY 0;SET KPNY 0.16;SET KPFY 0.25;
SET KDNY 0.003;SET KDFY 0.0005;
SET NEARY 7;SET FARY 24;
SET SHAPEY 1;
```

每次只改一个参数，分别比较持续移动、运动反向和移动后停止时的表现。远处跟不上可小幅提高远处P；
近处持续落后可提高近处P或减小近处D；停下后过冲可试少量增加近处D，但过大也会拖慢跟踪。
D作用来自误差变化率，不是单纯的电机摩擦阻尼，不能保证增大就一定减少所有过冲。

回到原来的双轴单P默认值：

```text
SET SHAPEX 0;SET KPX 0.55;SET KDX 0;
SET SHAPEY 0;SET KPY 0.18;SET KDY 0;
```

## 实现与验证

中间区域权重t=(|误差|-NEAR)/(FAR-NEAR)，平滑权重w=t*t*(3-2*t)。
P=P近+(P远-P近)*w，D=D近+(D远-D近)*w。
目标速度=P*误差+D*滤波后的误差变化率，再执行停止区、方向、限速、斜率等处理。
误差变化率仍采用0.06秒时间常数的一阶低通，长数据间隔、模式/中心/滤波窗口/微分参数/分区阈值变化时清除相关微分历史。

保持原14通道CSV，第9/10通道仍是KPX/KPY（分段时代表远处P），不是实时插值得到的有效P。
近处P、近远D和分区阈值不包含在这14个波形通道中，需记录发送值。
第13通道为命令计数，第14通道为最后一条命令结果。每条命令是独立生效，不是整批事务。
串口设置只存RAM，复位或断电后恢复默认值。
