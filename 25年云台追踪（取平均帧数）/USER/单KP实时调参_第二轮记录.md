# 单KP实时调参：第二轮

当前保存参数为KPX=0.42、SLEWX=260、ACCX=240，SHAPEX=0，最大X转速指令仍为15 RPM。原远距离增益/加速增强、参考中心与Y轴参数保持不变。

用户实机反馈：“相比之前是跟得上了，也能稳定，但是还是慢了一点”。因此本轮保存的是已确认有所改善且稳定的组合，不能表述为完全消除动态滞后。手动移动目标没有独立速度测量，各段并非严格受控条件下的性能排名。

## 保存与烧录

已写回`aim_control.h`：

```c
#define AIM_KP_X          0.42f
#define AIM_SLEW_X        260.0f
#define AIM_MOTOR_ACC_X   240U
```

备份：`aim_control.h.before_refine2_defaults.bak`，保持原文件编码。

当前运行参数已通过SerialPlot命令下发并确认回传KPX=0.42、命令计数70、结果1：

```text
SET SHAPEX 0;SET KPX 0.42;SET SLEWX 260;SET ACCX 240;SET MAXX 15;
```

新固件为`build/Template_Single_Refined2.hex`。当前在线值已生效，但本轮没有烧录：必须烧录这次生成的固件，重启后才会默认使用第二轮参数。此前`Template_Single_Tuned.hex`对应第一轮0.40/240/240，是回退版本。

修改后Keil编译0错误、0警告；串口解析、限速、失联停机、退出停机、14通道输出等ARM仿真回归通过。仿真不证明任意目标速度下都不发生过冲。

## 六行命令

P1：当前0.42/260/240；P2：上一轮已确认0.40/240/240，作为回退；P3～P6：对照候选。每行依次设置SHAPEX、KPX、SLEWX、ACCX、MAXX，点击Send才发送。候选行不是已确认的推荐组合。

原始数据在`build/group1_refine2_*.txt`，每行14通道，配套JSON记录参数和状态；`build/refine2_summary.json`保存完整本轮记录和最终保存状态。
