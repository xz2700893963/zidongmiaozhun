# USB 转 TTL 实时波形与调参

串口1现用于调参，不再接收 JY92 角度传感器。摄像头 UART5、两轴电机 USART2/USART3 保持原接口。

## 接线与烧录

先断开原角度传感器与 PA9/PA10 的连接。USB 转 TTL 使用 **3.3V 逻辑电平**，交叉连接：

| STM32 | USB 转 TTL 模块 |
| --- | --- |
| PA9 / USART1_TX | RXD |
| PA10 / USART1_RX | TXD |
| GND | GND |

开发板按原方式供电；板子已经供电时，模块的 VCC 不接。这里使用 TTL 串口模块，不能直接接 RS232 电平接口。

用 Keil 打开 `Template.uvprojx`，编译并通过原来的下载器烧录。USB 转 TTL 用于数据通信，未增加串口 Bootloader 下载功能。

## SerialPlot 设置

打开桌面的 SerialPlot，选择模块对应的 COM 口：

- 波特率：115200；数据位：8；停止位：1；无校验；无流控。
- Data Format：ASCII；通道数：14；数值分隔符：英文逗号 `,`。
- 每行一组数据，行尾 CRLF。固件默认每 50 ms 尝试发送一组，即约 20 组/秒；显示横轴若支持采样率设置，填 20 Hz。
- 点击 Open 开始读取。不要让另一个串口助手同时占用这个 COM 口。

通道顺序固定如下。可按下表重命名，先打开 1～4 通道观察参考值与当前值，再按需要显示其他通道。

| 通道 | 建议名称 | 含义 |
| --- | --- | --- |
| 1 | X_ref | X 瞄准参考值，默认 5 |
| 2 | X_actual | 摄像头 X，当前默认1帧，可在线选择1/2/3帧 |
| 3 | Y_ref | Y 瞄准参考值，默认 12 |
| 4 | Y_actual | 摄像头 Y，与X使用相同的平均帧数 |
| 5 | X_error | X_actual - X_ref |
| 6 | Y_error | Y_actual - Y_ref |
| 7 | X_cmd_rpm | X 电机有符号转速指令，单位 RPM |
| 8 | Y_cmd_rpm | Y 电机有符号转速指令，单位 RPM |
| 9 | KPX | 当前实际应用的 X 比例系数 |
| 10 | KPY | 当前实际应用的 Y 比例系数 |
| 11 | Valid | 摄像头反馈可用为 1；超时或持续零坐标判停为 0 |
| 12 | Active | 云台跟踪控制正在运行为 1 |
| 13 | Cmd_seq | 已处理的命令数量；发送命令后应递增 |
| 14 | Cmd_result | 最近一条命令结果：1 成功，-1 无效，0 尚无命令 |

坐标沿用摄像头原协议的数值/偏移量，不是电机角度。转速通道是控制指令，不是编码器实测转速。断流后 X/Y 会沿用原代码清零，此时用 Valid 通道区分“实际为零”和“反馈失效”。退出跟踪模式、摄像头超时和持续零坐标时仍按原策略发送零转速。

## 在线调参

在 SerialPlot 的 Commands 中添加 **ASCII** 命令。每条末尾带英文分号 `;`，无需依赖软件附加换行；固件也接受回车/换行结束命令。命令和参数名均大写。

| 发送示例 | 作用与允许范围 |
| --- | --- |
| `SET KPX 0.22;` | X 比例系数，0～2 |
| `SET KPY 0.10;` | Y 比例系数，0～2 |
| `SET CX 5;` | X 参考值，-32768～32767 |
| `SET CY 12;` | Y 参考值，-32768～32767 |
| `SET MAXX 15;` | X 最大转速，1～代码默认上限 15 RPM，整数 |
| `SET MAXY 10;` | Y 最大转速，1～代码默认上限 10 RPM，整数 |
| `SET SLEWX 40;` | X 转速变化限制，1～500 RPM/s |
| `SET SLEWY 25;` | Y 转速变化限制，1～500 RPM/s |
| `SET ACCX 100;` | X 驱动器加速度参数，1～255 整数，沿用驱动器定义 |
| `SET ACCY 60;` | Y 驱动器加速度参数，1～255 整数 |
| `SET PLOT 0;` | 暂停波形输出；命令接收、跟踪控制继续运行 |
| `SET PLOT 1;` | 恢复波形输出 |
| `SET AVG 1;` | 使用当前完整帧，默认1；也可设为2或3帧滑动平均，同时作用于X/Y |
| `RESET;` | 恢复 `aim_control.h` 中的默认调参值，并恢复波形输出 |

例如将 Y 比例系数改成 0.05：发送 `SET KPY 0.05;`，观察通道 10 变成 0.05，通道 13 递增，通道 14 为 1。参数在主循环解析，最迟在后续摄像头新帧的控制更新中使用，不需要重新烧录。电机指令为整数 RPM，小幅调参可能不会立即改变整数转速。

最大转速调低后，会在下一次有效控制更新中限制现有转速指令；在线命令不允许提高到代码原上限以上。停止带、重启带和远距离增强系数仍由原代码定义。平均帧数可通过AVG命令实时选择1、2或3；当前保存默认值为1。

当前改动暂存在 RAM，重启恢复默认值；`RESET;` 只恢复参数，不切换工作模式。当前已保存默认值为单KP=0.55、SLEWX=260、ACCX=240、AVG=1，固件为`build/Template_Single_AVG1_Tuned.hex`；必须烧录这个版本后，重启/RESET才会使用这些新默认值。此前版本仍恢复其各自默认值。控制参数默认值在`aim_control.h`，平均帧数默认值在`UART_maxcam.h`。

串口接收使用缓冲区，解析在主循环执行；波形通过发送中断输出，发送忙时跳过该次采样，避免等待串口拖住跟踪。命令过长、参数越界或无效数值会被拒绝。发生接收溢出/串口错误后会丢弃到下一个结束符；可先发一个 `;` 再重发完整命令。

移除角度传感器后，旧行走/航向控制里仍引用 `Yaw` 的功能不再有真实角度反馈。当前图像追踪不依赖该角度传感器。

## 验证

`tests/run_serial_tune_test.ps1` 使用本机 ARMCC 与 Python/Unicorn 执行命令、控制与串口中断仿真；需要 `build/test_deps` 中安装 `unicorn` 和 `pyelftools`。仿真不能代替真实开发板、USB 转 TTL 和摄像头的联调。
