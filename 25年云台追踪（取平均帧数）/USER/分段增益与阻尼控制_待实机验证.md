# X轴分段增益与阻尼：候选固件

**历史记录：本方案后续已停止使用。当前选定方案是单KP=0.40、SLEWX=240、ACCX=240，SHAPEX保持关闭。最终固件为`build/Template_Single_Tuned.hex`，参见`单KP实时调参_最终记录.md`。以下保留早期候选方案，不能当作当前推荐设置。**

针对低KP能稳住但移动跟随慢、高KP能跟上但过冲的反馈，增加可开关的X轴分段增益与误差变化率阻尼。此版本已编译和仿真验证，尚未烧录、尚未验证实机改善。

固件：`build/Template_Shaped_Control.hex`。Keil工程仍为`Template.uvprojx`，编译产物为`../OBJ/Template.axf`。本轮没有执行下载，没有向运行中的板子发送新控制命令。现有USB-TTL接线和14通道波形格式保持兼容。

## 新增命令（仅新固件支持）

| 命令 | 含义 |
| --- | --- |
| `SET SHAPEX 0;` | 关闭分段增益和阻尼，使用原控制器；开机/RESET后默认关闭 |
| `SET SHAPEX 1;` | 开启X轴分段增益和阻尼 |
| `SET KPNX 0.40;` | 近中心X比例系数，允许0～2；默认沿用原AIM_KP_X |
| `SET KPX 0.52;` | 开启新控制时为远处X比例系数；关闭时仍为原单一KP |
| `SET KDX 0.02;` | X误差变化率系数，允许0～0.10，默认0；单位RPM/(像素/秒) |

仅用于下一轮实机验证的起始组合：

```text
SET KPNX 0.40;SET KPX 0.52;SET KDX 0.02;SET SLEWX 240;SET SHAPEX 1;
```

这些值是候选值，不是已经验证的最终参数。旧固件不识别KPNX/KDX/SHAPEX，因此不要在烧录前将该命令当作已生效的调参组合。

回退原控制的示例：

```text
SET SHAPEX 0;SET KPX 0.40;SET SLEWX 240;
```

`RESET;`会关闭新控制并恢复代码默认参数，重启也一样。候选模式没有自动永久保存。

## 行为

- 单轴误差绝对值不超过7像素时使用KPNX，达到24像素时使用KPX，中间平滑插值。沿用原有远距离增益/加速增强，不能把KPX简单视为最终总增益。
- 使用60 ms一阶滤波后的误差变化率产生阻尼。误差正在减小时减小目标转速，误差增大时增加相应指令。它不是独立测得的目标速度，也不是完整的目标速度前馈。
- 阻尼允许提前降至零，但不在误差过零前要求反向。实际电机是否及时减速，仍取决于驱动器、机构和通信延迟。
- 启用/关闭模式、修改参考中心、摄像头失联、持续零坐标判停或退出跟踪时清除差分历史，避免首次恢复时的差分冲击。
- Y轴保持原算法；X/Y最大转速上限15/10 RPM、原停止带2像素和重启带4像素保持不变。

停止/重启区间意味着不保证逐像素精确停在零误差。最低整数转速、摄像头反馈延迟、机构惯性与参考点标定仍需实机检查；不能把此次算法改动作为消除静态偏差和动态滞后的保证。

第9通道仍输出KPX；在新模式下它表示远处增益，不是每时刻的插值增益。KPNX、KDX与模式尚无独立回传通道，命令结果只能确认最近一条命令是否被解析成功。14通道不会展示全部新参数。
